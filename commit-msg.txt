feat: 自用分流规则仓（Clash + Xray 双格式，自动构建）

一份自持规则（data/）编译成两种内核的产物，定时构建并发布。

产物：
- geosite.dat / geoip.dat  → Xray（ext:geosite.dat:<tag>），发布到 rules-latest Release
- dist/clash/*.yaml        → mihomo rule-provider（behavior: domain / ipcidr）

设计要点：
- 自持规则是单一真相，改规则只改 data/；新增列表 = 丢一个文件，不用改脚本
- 公共规则集不合并进产物，在客户端配置里以引用方式并用（可复现 + 可切换），
  可引用清单记录在 sources.yaml
- keyword:/regexp: 会让该列表整体改用 classical 输出（behavior: domain 表达不了），
  构建时打印提示，避免规则静默不生效

校验（关键）：scripts/verify.sh 用真实内核加载产物
- Clash：真启动 mihomo 查 /providers/rules 的 ruleCount 并与 MANIFEST 对齐。
  **不用 `mihomo -t`** —— 实测它只校验配置语法、不加载 type: file 的
  rule-provider：文件写成非法 YAML 甚至删掉，`-t` 都报 successful 退出码 0。
- Xray：xray run -test 加载 ext: 引用的 .dat
- 两侧都带变异检验（缺文件/坏内容/空规则集/条数不符必须报错），
  本地实测 mihomo 侧 4/4 变异全被抓到、基线恢复通过

内核：mihomo v1.19.32 / Xray v26.9.30（Xray 新版走 pre-release，
`releases/latest` 只指到 v26.3.27，CI 取最新一个 release 含 pre-release）。
